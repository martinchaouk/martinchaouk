## Hi, I'm Martin

I'm finishing an MSc in Computer Science at UCL. Before that I did an MSc in
Statistics, an BSc in Applied Mathematics and spent a year as a data analyst in Taiwan,
so most of what I build sits somewhere between data and software.

My MSc thesis was a document extraction service built with Digital Bridge Labs
and IBM for the Government of Bangladesh. It reads the paperwork for a garment
export shipment, checks the documents against each other, and decides what can
be accepted automatically and what needs a person to look at it.

### Things I've built

- **[Trade document extraction](https://github.com/martinchaouk/trade-doc-extraction)** –
  my MSc thesis. Reads a shipment's invoice, packing lists, bill of lading,
  certificate of origin and letter of credit, then runs 22 cross-document checks.
  I compared an OCR pipeline, a vision model and an LLM agent on hand-labelled
  data (write-up only, the code is private)
- **[Infusion](https://github.com/martinchaouk/infusion-notes)** – career
  development platform on Next.js, Prisma and PostgreSQL, built as a UCL group
  project. I built the Q&A, job postings and applications, and organisations
  features, and the Docker/Nginx deployment on Azure (write-up only, the code is private)
- **[Predator–prey simulation](https://github.com/martinchaouk/ecosim-notes)** –
  agent-based simulation in C++17 that runs serially, with OpenMP, or split across
  4 MPI processes with ghost animals at the boundaries (write-up only, coursework
  code is private)
- **[Online auction platform](https://github.com/martinchaouk/php-fullstack-auction)** –
  eBay-style site in vanilla PHP and MySQL, built with three classmates. I did the
  watchlist, seller ratings, bid dashboard and account pages, plus the DB
  constraints that stop duplicate watches and ratings
